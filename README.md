# plexciton
Package for the analysis of the absorption, photoluminescence (PL), lifetimes, and Raman (from plasmonic, excitonic, and conjugated sytems).
Absorption spectra: Cary 3500 UV-Vis
PL: Cary Eclipse Fluorescence Spectrophotometer
Time-resolved confocal fluorescence microscope MicroTime 200 SymPhoTime 64 software
Confocal Raman microscopy setup (Alpha300, WITec)
